
# Problem Definition

## The Problem

Financial analysis often requires collecting company data,
calculating financial ratios, and comparing performance
across multiple companies.

Performing these calculations manually can be time-consuming,
repetitive, and prone to errors.

## Project Objective

The goal of this project is to develop a Python-based
financial analysis system that automates basic company
financial analysis.

The system should:

1. Read financial data from structured CSV files.
2. Calculate key financial performance metrics.
3. Compare financial performance across companies.
4. Generate visualizations of financial metrics.
5. Provide a foundation for future AI-powered analysis.

## Current Scope

Version 2 analyzes fictional company data using four metrics:

- Profit Margin
- Revenue Growth
- Return on Assets (ROA)
- Return on Equity (ROE)

The program generates comparison charts and identifies
the company with the highest value for each metric.

## Future Goal

The long-term goal is to develop an AI-powered financial
analysis agent capable of interpreting financial information,
researching companies, and generating financial insights.

## Limitations

- The current dataset contains fictional companies.
- Financial data must be provided in CSV format.
- The program does not retrieve real-time financial data.
- The current version does not use artificial intelligence.
- Higher financial ratios do not necessarily indicate
  a better investment.
